# TV Accent Wall Planner

A client-side 3D concept configurator for a custom TV accent wall: pick finishes step by step (or start
from a preset), orbit the live 3D preview, then download or email a structured project summary.

Plain HTML, CSS and JavaScript with [Three.js r128](https://threejs.org/) from a CDN. No build step,
no backend; nothing is sent anywhere unless you press Send (which opens your own email app).

"Northline Interiors" is a placeholder brand. Edit `config.js` to change the brand, options and presets.
